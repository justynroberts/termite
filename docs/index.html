A terminal client that doesn’t assume you only have one server.

SSH sessions in tabs and split panes, SFTP, port forwarding, and a host vault with agent, key and bastion support. Run a step across forty machines and watch the exit codes come back. Wire up an LLM with your own API key, or leave it off.

Electron and xterm.js, on macOS and Windows. MIT licensed. No account, no telemetry, no server in the middle.

Terminal
Up to 8 live panes per tab, WebGL renderer, Powerline and Nerd Font glyphs, 10 themes.
Fleet
Multi-step runbooks across many hosts, parallel or rolling, with per-host exit codes.
LLM
Bring your own Anthropic key. Reads your scrollback on request. Nothing runs unattended.
macOS .dmg · universal Windows .exe · x64 Source

macOS builds are signed and notarised — they open without a Gatekeeper prompt. Windows builds are unsigned; SmartScreen asks once.

Install

Builds are attached to each GitHub release. No package manager yet.

macOSTermite-<ver>-mac.dmg — universal, Apple Silicon and Intel. Signed with a Developer ID and notarised, so it opens normally and updates itself in the background.
Windows installerTermite-Setup-<ver>.exe — x64, per-user, choose your own install directory. Updates itself in the background.
Windows portableTermite-Portable-<ver>.exe — no install. Tells you when a new version exists; replace the file yourself.
From sourcenpm install, then npm run dev. Node 22, no native toolchain needed.

Terminal

xterm.js on the WebGL renderer, 256 colour.

Panes and tabs

  • Up to 8 panes per tab in columns and rows, each its own SSH session.
  • Panes collapse when their shell exits. Ctrl+Shift+W closes one directly.
  • Open tabs and split layouts are restored after restart, with fresh connections.
  • Duplicate a session to open a second independent connection to the same host.
  • Synchronised input broadcasts typing to every pane in a tab, with an armed state you cannot miss.
  • Zen mode (Ctrl+Shift+Z) hides all chrome.

Fonts and glyphs

  • Core Powerline glyphs are drawn by the renderer, so they work in any font.
  • Symbols Nerd Font is bundled for the extended set; a system Nerd Font is preferred when present.
  • JetBrains Mono, Fira Code, IBM Plex Mono and Source Code Pro ship with the app.
  • 10 themes: Dracula, Nord, Tokyo Night, Catppuccin, Gruvbox, One Dark, Monokai, Solarized dark and light, Termite Dark.

Clipboard

  • Ctrl+C copies when there is a selection and sends SIGINT when there is not.
  • Ctrl+Shift+C always copies; right-click copies a selection or pastes.
  • Optional copy-on-select, PuTTY style.
  • Multi-line pastes ask for confirmation before they reach the shell.

Fleet management

Runbooks: ordered steps, each targeting one host or many.

TargetingEach step picks its own hosts. Run them in parallel, or roll one at a time.
FailureFail-fast or continue-on-error, set per step. Optional per-step timeout.
InterpreterLogin shell, bash, or PowerShell for Windows hosts — chosen per step.
While runningStep timeline, per-host status and exit codes, streaming output you can collapse, cancel mid-run.
DraftingDescribe the job and the LLM writes the steps — pre-checks, change, verification — for you to review and target before anything runs.
Audit30 days of local activity: connections, transfers, runbook starts and cancels. On your machine, not sent anywhere.

Hosts, auth and keys

VaultGroups, tags, colours, search. Double-click connects; right-click edits. Import from ~/.ssh/config.
AuthPassword, private key, or agent — Windows OpenSSH agent and SSH_AUTH_SOCK.
BastionsJump host chaining for anything not directly reachable.
Host keysPinned on first use. A changed fingerprint refuses the connection. Pins are listed and removable in settings.
Key generationed25519 in OpenSSH format, or RSA-4096. Copy the public key for authorized_keys, or import one you have.
Per hostEnvironment variables and startup commands that run on connect.

Files and tunnels

SFTPDual-pane local and remote. Whole directories up or down with live progress. mkdir, recursive delete, rename, chmod, path bar, multi-select.
ForwardingLocal, remote and dynamic (SOCKS5), each started and stopped from the same window as the shell using it.
SnippetsSaved commands, sent to the focused pane.

LLM connectivity

Optional. Off until you paste a key, and it is your key.

ProviderAnthropic. Your key is stored encrypted by the OS keychain and sent to the Anthropic API and nowhere else. There is no Termite server.
ContextWhen you ask it to explain an error or some output, it is given the recent scrollback of the focused pane. Otherwise it sees nothing.
CommandsDescribe what you want, get a command back with Run, Insert and Copy. Nothing executes until you click. Destructive commands come back with guardrails attached.
AlsoExplain output, summarise a session, draft a runbook, or plain sysadmin chat. Ctrl+K opens it.
Without a keyEverything else works. No prompts, no upsell, no calls out.

Where data lives

  • Passwords, private keys, passphrases and the API key are encrypted with the OS keychain — DPAPI on Windows, Keychain on macOS, via Electron safeStorage — before they touch disk. They sit in termite-store.json in the app's user-data folder.
  • The renderer never receives a stored secret. SSH runs in the main process behind a typed IPC bridge with contextIsolation on.
  • Host keys are pinned on first use; a mismatch refuses the connection.
  • The activity log is local and keeps 30 days.
  • No account, no sign-in, no telemetry. The only outbound calls are SSH to your hosts, GitHub for update checks, and Anthropic if you configured a key.
Updates. Termite checks GitHub Releases shortly after launch, every couple of hours, and on window focus. It skips the check while a runbook or transfer is running, and it never restarts without asking — the dialog says how many sessions the restart will disconnect. Turn it off in Settings → Updates.

Build it yourself

git clone https://github.com/justynroberts/termite
cd termite && npm install

npm run dev           # hot reload
npm run typecheck     # both tsconfig projects
npm run package:mac   # dmg + zip, universal
npm run package:win   # installer + portable

Signed macOS builds need a Developer ID in the keychain and a stored notarytool profile; see package:mac:signed.
