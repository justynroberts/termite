01 — AI Copilot · Ctrl / Cmd + K

It has already read your error.

Most tools bolt a chat box onto a terminal. Termite hands the copilot your actual recent output, so “explain last error” explains yours — not a plausible one. Describe what you want in English, get the exact command back with Run, Insert and Copy next to it. Nothing executes until you click.

  • Explain last error — reads the real scrollback of the focused pane
  • Explain output and summarize session for long-running work
  • Destructive commands come back with guardrails attached
  • Bring your own Anthropic key — it is sent to Anthropic and nowhere else

02 — Runbooks

Patch the fleet, not the host.

Multi-step, multi-host orchestration built into the client you already have open. Each step targets one or many hosts, in parallel or rolling one at a time, with fail-fast or continue-on-error per step. Describe the job in plain English and Claude drafts the steps — pre-checks, change, verification — for you to review before anything runs.

  • Live run view: step timeline, per-host status and exit codes
  • Streaming collapsible output, cancel mid-run
  • Per-step interpreter — login shell, bash, or PowerShell for Windows hosts
  • Optional timeouts per step

03 — Terminal

Powerline that just renders.

xterm.js on the WebGL renderer, 256 colour. The core Powerline glyphs are drawn by the renderer itself in any font, and Symbols Nerd Font ships in the box for the extended set — so your prompt looks right on a machine you set up ten seconds ago. Up to eight live panes per tab, and Zen mode to throw every scrap of chrome away.

  • Clipboard done right — Ctrl+C copies on a selection, SIGINT otherwise; optional copy-on-select
  • Panes auto-collapse when their shell exits
  • Windows 11 Mica / Acrylic materials; macOS vibrancy
  • Dracula, Nord, Tokyo Night, Catppuccin, Gruvbox, One Dark, Monokai, Solarized…

04 — And the rest of the job

One app, end to end.

01 Host vault

Groups, tags, colours and search. Double-click to connect, right-click to edit, row buttons for terminal / SFTP / edit / delete. Import straight from ~/.ssh/config.

02 Auth & bastions

Password, SSH key and SSH agent (Windows OpenSSH agent and SSH_AUTH_SOCK), with jump-host chaining for anything behind a bastion.

03 Keys

Generate ed25519 or RSA-4096 in-app, copy the public key for authorized_keys in one click, or import a private key you already have.

04 Files

Dual-pane local ⇄ remote SFTP. Upload and download whole directories with live progress; mkdir, recursive delete, rename, path bar, multi-select.

05 Tunnels

Local, remote and dynamic SOCKS5 port forwarding, each with start/stop control from the same window as the shell using it.

06 Snippets

Save the commands you type constantly and fire them into the focused pane with one click.

06 — Security

The renderer never sees a single secret.

Passwords, private keys, passphrases and your API key are encrypted with the OS keychain — DPAPI on Windows, Keychain on macOS, via Electron safeStorage — before they touch disk. All SSH runs in the main process behind a typed IPC bridge with contextIsolation on.

  • Host keys pinned on first use (TOFU); a changed fingerprint refuses the connection
  • Your Anthropic key is only ever sent to the Anthropic API
  • No account, no sign-in, no telemetry
  • MIT licensed — read the whole thing on GitHub
